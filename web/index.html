MandateCourt

A GenLayer jury for one question: the agent paid inside every signed limit, was it still what the person asked for?

How it works

  1. Plain code first: size, hash, receipt signature and scope limits. A malformed or out-of-limit case never reaches a model.
  2. The validators read the payment and the grant from Solana devnet and must agree on them.
  3. The model sees only text a party signed: the purpose, the chain facts, the seller's signed receipt. Free text is ignored.
  4. Five validators, each with a different model; the leader answers and the others re-judge it.
  5. The answer is one of four fixed triples (verdict / liable party / reason). Unsure means could_not_decide.
